# Mobile brand header alignment

The shared welcome, login and consent brand header places the Descon logo and MPS Connect on one centered row. Urdu reverses the row so the logo sits on the right, with explicit RTL lettering and sufficient line height. The name remains on one line, can shrink on narrow screens, and the logo retains its size.
