# Finance default fee layout

The payment transactions heading now leads the page. The default onboarding fee appears directly below it as a compact blue strip, aligned with the transaction summary and filters. The amount sits beside the title and the primary Edit fee action includes a pencil icon. English and Urdu help text is shorter. Candidate fee cards retain their existing layout and all fee editing, validation and permission rules remain unchanged.
